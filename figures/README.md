# Figure provenance

## Generated in this repository

- `moose-anisotropic-phase-field-t0.140556.png` is a rendered checkpoint from
  the MOOSE `snow.i` anisotropic-interface example, executed locally with the
  official MOOSE binary. The governing implementation follows Ryo Kobayashi's
  one-component phase-field model for dendritic crystal growth.
- `reduced-rust-baseline-seed319.png` and
  `reduced-rust-photon-bias-seed319.png` are direct outputs of the reduced Rust
  model in this repository.
- `reduced-rust-frontier-follow-seed319.png` is the final live frame from the
  first frontier-following photon loop.
- `frontier-follow-trajectory.png` plots the recorded conductive frontier and
  photon-band center from that same run. It is generated by
  `simulation/plot_frontier_follow.R`.
- `reduced-rust-cherenkov-seed319.png` is the final live frame from the first
  two-dimensional Cherenkov-cone test (`n = 1.33`, `beta = 0.99`).
- `cherenkov-bootstrap-paired.png` shows the paired bridge-step and
  occupied-cell differences across seeds 1 through 128. It is generated by
  `simulation/analyze_bootstrap.R` from the committed paired result table.
- `voltage-routing-benchmark.png` compares conductance per interconnect and
  post-cut flux retention for the straight wire, five-rail grid, first grown
  topology, and recurrently developed topology using MOOSE results.
- `developmental-transect-bootstrap.png` shows repair time across the observed
  guaranteed-transection horizon for 64 independent seeds.
- `progressive-targeted-ablation.png` shows MOOSE terminal flux after lesions
  aimed sequentially at each topology's shortest surviving path.
- `field-stress-boundaries.png` compares integrated Joule density at equal
  voltage and equal delivered current using MOOSE-computed field gradients.
- `current-driven-remodeling.png` shows the actual morphology before and after
  24 alternating MOOSE field solves and local current-driven widening epochs.
- `tin-whisker-voltage-ramp.png` applies measured NASA fusing-current data to
  a circuit-impedance and voltage sweep.
- `cherenkov-recurrent-development.png` and
  `cherenkov-recurrent-development.mp4` preserve the seed-319 developmental
  topology and its cut-and-regrow sequence.
- `LIV_IRIDIUM_NIOBIUM_JUPITER.png`,
  `LIV_IRIDIUM_NIOBIUM_SATURN.png`, and
  `LIV_IRIDIUM_NIOBIUM_TITAN.png` are fully labeled dual-lineage topology
  probes. `LIV_IRIDIUM_NIOBIUM_PLANETS.mp4` shows their actual formation.
