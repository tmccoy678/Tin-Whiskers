# Figure provenance

## Generated in this repository

- `moose-anisotropic-phase-field-t0.140556.png` is a rendered checkpoint from
  the MOOSE `snow.i` anisotropic-interface example, executed locally with the
  official MOOSE binary. The governing implementation follows Ryo Kobayashi's
  one-component phase-field model for dendritic crystal growth.
- `reduced-rust-baseline-seed319.png` and
  `reduced-rust-photon-bias-seed319.png` are direct outputs of the reduced Rust
  model in this repository.
